# Retained practice recordings and retelling feedback (T112)

`practice-retelling` is an immutable `game_sessions` event mode. The existing backup payload and append-only account sync carry its versioned, Zod-validated detail. There is no new table, settings registry key or server contract. Completed T106/T110 responses are never edited.

Explicit **Keep recording** copies the exact WAV bytes to `recordings/practice/practice-<uuid>/original.wav`; metadata carries SHA-256, bytes, duration, attempt/context, stage, assistance and repetition. Only this explicit operation retains a take. Cache takes remain temporary. The 128 MiB local quota refuses new keeps/restores; it does not silently evict user audio. `media-deleted` is a tombstone, while local eviction keeps metadata and the restore option. The UI explains that previously uploaded encrypted archives are immutable: the current server has no media DELETE endpoint.

The existing `bundle-service` adds a practice source to its SMB1 → encrypted media envelope → enabled backup targets → lazy restore flow. Existing `sumrak-media-practice-<uuid>.json` names fit the server allowlist. Upload and restore validate the exact recorded checksum; restore also checks quota and deletion state. Metadata backup alone is not an audio backup. No remote writes are needed for host tests.

ASR produces immutable `asr-original` text with model provenance. Each explicit correction/confirmation creates another record linked to that original. Only confirmed ASR or the original typed completed response can feed optional story feedback. No unconfirmed recognition becomes an established mistake.

Feedback uses the existing OpenRouter runner and queue wakeups. The request fixes the input, source companion version, requested model, rubric, assistance/repetition and owner device. A durable `feedback-started` record is written before a send. One device owns a request; concurrent pump triggers join; dispatched requests are never automatically resent after failure/restart. Returned results are cached locally before the immutable final record is written, so a save retry need not charge again. Cancellation aborts the request where possible and suppresses late results. The UI explains that an already dispatched request may have been charged. An explicit new review creates a new request and preserves older ones.

Only bundled NoEnd House case-file/transfer references are allowed into prompts; no exam repository or held-out corpus is queried. Feedback is text-only coaching, not a TORFL/CEFR score or phonetic assessment. Schema checks reject unknown evidence IDs, invented quoted corrections and audio-assessment claims. The notebook lists these reflections separately without counting a regrade or recognition correction as a fresh unaided success.

Tests cover exact-byte preservation, storage limits, rollback, deletion/eviction, encrypted SMB1 roundtrip, metadata backup/restore and two-database fake-server sync, ASR provenance, offline/key gates, single dispatch, foreign-device exclusion, cancellation/late completion, cached finalization, regrades and unsupported claims. T111 owns real-device capture/playback and data-restoration evidence.
