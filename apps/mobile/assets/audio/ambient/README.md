# Ambient study soundtracks (M15)

Generated by `apps/mobile/scripts/encode-ambient-beds.mjs` — run `pnpm --filter sumrak-mobile encode:ambient` (see `docs/RUNBOOK.md` §6). Do not hand-edit `beds.json` or the `.opus` files: the script rewrites both and `features/ambient-audio/__tests__/beds.test.ts` reconciles the ledger with the hand-written registry `features/ambient-audio/beds.ts`.

Masters (Suno WAVs + the horror MP3) live **outside the repo** in the workspace-root `assets/audio/`. Every bed is Ogg Opus, stereo, 48 kHz, 96 kbps VBR, normalised to −26 LUFS / −2 dBTP (design `AMBIENT_SOUNDTRACKS.md` §4, ADR-0017).
